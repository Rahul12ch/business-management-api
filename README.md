# Business Management System - Backend

## Overview

This is the ASP.NET Core Web API backend for the Business Management System. It provides secure REST APIs for managing customers, tasks, invoices, payments, authentication, and email notifications.

## Live API

https://business-management-api-49uh.onrender.com

## Technologies

- ASP.NET Core (.NET 10)
- Entity Framework Core
- PostgreSQL (Supabase)
- JWT Authentication
- Render
- Resend Email API

## Features

- User Authentication
- Customer Management
- Task Management
- Invoice Generation
- Payment Tracking
- Email Notifications
- RESTful APIs
- Secure JWT Authentication
